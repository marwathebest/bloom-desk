وش يسوي Bloom Desk؟

صُمّم للمبرمجين وصنّاع المشاريع اللي عندهم مشاريع كثيرة ووقت قليل

📂

مشاريعك في مكان واحد

اسحب مجلد المشروع وافلته، ويتعرّف بنفسه على النوع (Flutter، أو React، أو موقع)، والاسم، ورابط GitHub، والموقع المنشور.

▶️

شغّل بضغطة، بدون إحراج

زر واحد يشغّل المشروع بالأمر الصحيح، وينتظر السيرفر إلى أن يجهز، ويفتح المتصفح لحاله. والمشاريع المنشورة تفتح موقعها الحقيقي.

✅

جهّز للعرض

قبل الاجتماع يفحص كل مشاريعك: 🟢 جاهز، و🟡 يحتاج تجهيز (ويصلّحه بضغطة)، و🔴 فيه مشكلة. ويصحّي المواقع النايمة مسبقاً.

🌱

جلسة تركيز

تختار المشروع والمدة، ووردة بلونه تكبر مع وقتك. خلّصت؟ تتفتح 🌹. وجتك فكرة وسط الشغل؟ اكتبها بسطر وكمّل.

☕

راحة تستاهلها

بعد كل جلسة تذكير هادئ: 💧 اشرب ماء، و🧘 تمدد، و👀 قاعدة 20-20-20 لعيونك.

🌷

حديقة اليوم

وردة لكل جلسة، وشريط يوضّح وين راح وقتك لكل مشروع، وكل أفكارك الطارئة مجمّعة. وترجع لأي يوم قبل.

التثبيت

دقيقة وحدة، وما يحتاج صلاحيات مدير

  1. حمّل BloomDesk-Setup.exe من الزر فوق
  2. افتح الملف، واختر إذا تبي أيقونة على سطح المكتب، واضغط Install
  3. افتح Bloom Desk من قائمة ابدأ، واسحب أول مجلد مشروع 🌸
⚠️ طبيعي يطلع لك تحذير أزرق من ويندوز مكتوب فيه "Windows protected your PC"، لأن البرنامج جديد وما عليه توقيع رقمي مدفوع. اضغط More info ثم Run anyway. والكود كامل مفتوح على GitHub لأي أحد يبي يتأكد منه.
